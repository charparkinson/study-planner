## About

### I wanted to create a desktop study planner to help me during my time at university. It is important to me that I have a desktop planner rather than a physical paper copy, as I am very prone to losing things and want to have a desktop version since I will be spending a lot of my time on my laptop during my degree.

### There are lots of online planners already available, including online calendars. However, I want to create my own to be able to personalise it and adapt it to my needs (I am neurodivergent). This project is a great way for me to get into a studious headspace in the weeks leading up to my degree, and refresh my memory of the coding skills I learnt and practised during my time with Code First Girls, especially because I will be using Python and other coding languages at university.

### My goal for this project is to create a personalised study planner that will help me to organise my assignments, my scheduled study sessions, and live tutorials into a diary or calendar. I also want it to help motivate me when I feel I am falling behind and wanting to give up (something that I experience all the time).

### When I see lots of tasks in front of me, I panic and my immediate reaction is to quit. It can feel overwhelming, stressful, and scary. A feature I want this planner to include is a button I can press when I feel this way. In response, the planner will be able to go into 'overwhelmed mode'. This is where the app will adjust the brightness to a dim light, mute any bright colours on the screen, reorganise the tasks based on how urgently they need to be completed, and only show one or two tasks that need to be completed to prevent sensory overload which can add to my emotional dysregulation. 

### When these tasks have been completed, it will check in and send a prompt to see if I am ready for another task or if I would like to stop for the night. It will prompt me to take care of myself by sending out a positive affirmation and a slow and gentle self-care idea that I can complete.

### I am hoping that by incorporating this feature into my project, I have a better chance of completing my degree.
